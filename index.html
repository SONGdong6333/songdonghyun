MD Studio 도움말

기본 사용법

  1. 파일 → 열기를 눌러 기존 Markdown 파일을 불러옵니다.
  2. 왼쪽 편집창에서 Markdown 문법으로 내용을 작성하거나 수정합니다.
  3. 오른쪽 화면에서 변환된 결과를 실시간으로 확인합니다.
  4. 파일 → Markdown 저장으로 수정한 내용을 저장합니다.

HTML / PDF 내보내기

  • 내보내기 → HTML 파일로 내보내기: 미리보기 내용을 독립 HTML 파일로 다운로드합니다.
  • 내보내기 → PDF로 내보내기: 인쇄 창에서 대상 프린터를 PDF로 저장으로 선택합니다.

편집 도구

  • 제목: 제목(##) 문법을 삽입합니다.
  • 코드: 코드 블록을 삽입합니다.
  • 표: 기본 2열 표를 삽입합니다.

참고: 이 앱은 별도 설치 없이 HTML 파일을 브라우저에서 열어 사용하는 단독형 편집기입니다.
